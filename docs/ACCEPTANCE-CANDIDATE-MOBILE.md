## 第二項：手機網站操作展示

> **這是以 Playwright 的 Chromium 行動版模擬（390×844、2 倍解析度、觸控）操作本機預覽網站的錄影，不是 iPhone Safari 或 Android 實機測試。**

### 交付檔案

| 檔案 | 說明 |

| `docs/screenshots/mobile-demo/01–20-*.png` | 依操作順序的 20 張關鍵畫面（2 倍解析度截圖，比影片清晰） |

畫面下方的深色說明框、橘色圈選框與點擊圓圈，是**錄影時另外疊加的示範標註**，不是網站內容，也不會出現在網站上。

### 操作順序

| 步驟 | 操作 | 關鍵畫面 |
|---|---|---|
| ① | 開啟首頁，圈出右上角「切換畫面」 | 01、02 |
| ② | 緩慢往下捲動：六大分類 → 編輯精選 → 需求入口 → 城市資源 → 官方資源 → 學習活動 → 關於 → 頁尾；在中段與底部圈出「切換畫面」 | 03–07 |
| ③ | 捲回六大分類，點擊「法律與權益」卡片，切換到 `law.html` 並往下捲動 | 08–10 |
| ④ | 按瀏覽器「返回」回到首頁 | 11 |
| ⑤ | 點首頁搜尋框，逐字輸入「法律扶助」，顯示搜尋結果浮層 | 12 |
| ⑥ | 開啟手機選單（圈出「切換畫面」仍在原位）→ 關閉選單 | 13–15 |
| 補充 | 由選單前往「支援資源與求助專線」，在頂端與中段圈出「切換畫面」 | 16、17 |
| 切換 | 點擊「切換畫面」→ 立即前往 Google；再按「返回」回到首頁，而不是求助頁 | 18、19 |
| 結尾 | 顯示提醒：不會清除瀏覽紀錄，也無法保證他人無法察覺使用活動 | 20 |

錄影環境的網路政策無法連到 google.com，所以「前往 Google」後的畫面是**替身頁**（頁面上有標示）。網址確實是 `https://www.google.com/`，切換行為（`location.replace`）是網站實際程式。
