## 二、設計主張（直接執行這一版，不用再做多種備選消耗額度）

**做一個與其他快捷方框明顯不同、但融入成熟編輯式視覺的「動態資訊小櫥窗」。**

- **位置**：維持在首頁四個快捷入口下面，目前 `activitiesEntry()` 原位置。保留整區塊可點擊並導向 `activities.html`，不要多加無作用按鈕。
- **結構**：橫向特色入口，大約手機高度 **144–176px**（隨內容自適應），不要僅一行 pill；品牌暖米白／奶油白、琥珀陶土棕、低飽和鼠尾草／橄欖綠。醒目但安靜，沒有高彩度、卡通 3D、人物圖、對外機構商標。
- **固定文字**：大標「活動與講座」，小字「探索理財、職涯、健康、藝文與各種生活學習活動。」；可增加明確的「查看活動資訊 →」。標題與點擊提示**一直可見**，不得因輪播更換、消失或閃爍。
- **真正動的部分**：同一卡片另一側／局部區塊，是自行用 CSS + inline SVG 或 HTML 組成的「三張錯位堆疊的小型活動紙卡／日曆頁」小場景。紙卡有細線、簡短虛線／抽象符號表示課程、展演、學習，**不展示虛構活動名稱、日期、剩餘名額或報名中狀態**。
  - 每次循環約 **6–9 秒**：前景紙卡輕微上浮＋往側邊滑開淡出，下一張慢慢接上，上一張退到底層；3 張的層次交替，帶停頓，讓訪客在正常閱讀首頁時可辨認場景「有動」。
  - 只用低幅度 transform／opacity，**不應造成整區塊尺寸位移、文字抖動或其他內容跳動**。
  - **持續循環**而非只播放 0.7 秒淡入／箭頭兩次後永久停住；避免高頻快速閃爍與刺激效果。箭頭可以在 hover 有輕微動作，但不能當作主動畫。
  - 整個畫面仍是**單一首頁入口**，不是新增文章預覽、橫向課程清單、第二套目錄或一場真實活動。
- **窄手機**：320／375／390px 實測不水平溢位、不蓋字、不佔掉巨幅首頁空間；文字及圖像可並排、過窄時圖像縮放，必要時改合理上下層。保持至少 44px 有效點擊區。
- **減少動態效果**：`prefers-reduced-motion: reduce` 時**停掉所有循環動作**，保留有層次而能理解的靜態畫面；不要把整個場景隱藏。
- **無外部授權素材／API**：優先純 CSS 與原創簡易 SVG；不用 GIF、外部動畫套件、Lottie、追蹤程式、額外付費服務。
- 需遵守 `docs/VISUAL-STANDARD.md` 品牌方向，特別是暖米白色盤、成熟清楚、避免全部做成一模一樣的卡片矩陣；不修改永久規格原檔。

## 三、驗收要能證明「真的動」

**純粹截圖、CI 綠燈或 CSS 中出現 `animation:` 不等於視覺驗收。**

- 提供一段 **8–12 秒**的 375 或 390px 手機版錄影（Playwright 畫面錄製亦可），讓站主一眼看到 2 次以上明確紙卡切換；另提供 320px 靜態截圖檢查字有沒有被蓋。
- 自動測試至少檢查：在一般動畫設定下，紙卡主圖層於兩個不同時間點的 `transform` 或 `opacity` 實際變化，超過首輪 3 秒後仍持續循環；降低動態效果時 animation 無動作。不要用會不穩定的微秒精度測試。
- 入口仍指向 `activities.html`、活動頁 12 筆查詢資料與搜尋不變、讀利／向光已驗收目錄不變、QA noindex＋未核准告示。
- preview／production HTML 和正式核准資料不變；若共用 CSS 新增僅在 QA 使用的新 class 可以接受，但不能傷害正式版原視覺。
- **只在工程分支改動後回報**：commit SHA、CI、手機錄影及截圖、變動範圍；**未經站主再次同意不得更新公開 QA**。
