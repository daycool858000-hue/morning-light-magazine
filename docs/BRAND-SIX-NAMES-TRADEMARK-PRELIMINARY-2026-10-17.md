## 已找到的來源（連結只供查核，不以對方品牌做網站素材）

1. **臺灣官方文字與圖樣商標資料庫**：[智慧財產局商標檢索](https://cloud.tipo.gov.tw/S282/S282WV1/)；官方說明資料包含申請、註冊、核駁案件，資料更新公告2026-10-11，且新申請到可查有建檔落差。這次已打開檢索入口和政府開放資料介紹，但**無法操作其中需要填表提交的「相同／文字近似」檢索並取得六組逐案結果，因此所有六組的臺灣商標註冊狀態尚未驗證**。
2. **智慧局公開資料**：[商標申請案API資料集](https://data.gov.tw/dataset/41664)，含三百多萬歷史申請案資訊；直接取得前10筆API並不能查完六組名稱。API本身資料亦非個案司法侵權判定。
3. **《向光》臺灣實際同名出版**：[國家人權博物館出版品](https://www.nhrm.gov.tw/w/nhrm/Publishing?index=4)、[官方館藏展示](https://www.nhrm.gov.tw/w/nhrm/index/ExhibitionB)、[國家文化記憶庫第12期](https://tcmb.culture.tw/zh-tw/detail?id=2246635&indexCode=Culture_Object)。另臺灣文學年鑑列《向光》2019-11創刊，半年刊，出版單位國家人權博物館。
4. **「由己」海外／同名App**：[在臺灣可開啟的同名App](https://apps.apple.com/tw/app/%E7%94%B1%E5%B7%B1/id1634342655)；[海外第42類「由己」品牌敘述](https://www.newton.com.tw/wiki/%E7%94%B1%E5%B7%B1)為二手百科資料，尚未直接核對海外登記簿；不能推論臺灣商標註冊存在。
5. **法律判斷基準**：[TIPO相同／近似查詢方法](https://www.tipo.gov.tw/tw/trademarks/568-7691.html)；[類似商品／服務判定](https://www.tipo.gov.tw/tw/trademarks/568-7710.html)；[描述性／其他例外使用說明](https://www.tipo.gov.tw/tw/trademarks/568-7607.html)。商標衝突須結合在臺有效權利、商品服務類別、整體名稱與是否混淆等多項因素。
6. **分類官方參考**：[2026商品服務分類資料](https://www.tipo.gov.tw/tw/trademarks/979.html)。初步優先第41類線上出版／教育資訊；依網站具體情況加看第16類（紙本出版可能的相近標示）、第42類（網站相關服務）、第35類（資訊及廣告相關服務）與第45類（法律資訊相關），**不能只用不同類別就斷定完全不相似**。

## 目前站主不必做的事

- 不因中國大陸「由己」商標而立即停止臺灣網站或支出申請費；需要查在臺灣權利是否存在。
- 不因國家人權博物館《向光》刊名而直接宣告侵權或擅自修改已確認的欄目，**這是優先查核提示**。
- 網站卡片只用自行設計的概念圖示，不重製他人官方標誌、照片、版面；站方不聲稱是任何政府機關的合作或認可單位。

## 必須完成才能結案的第二輪

1. 由可操作表單的瀏覽器在TIPO輸入全部六組文字及拼寫變體，查所有**申請中／註冊有效**與近似，尤其41類及相互檢索組群。
2. 對命中案件逐筆記：案號、權人、有效／失效、日期、分類、指定商品／服務及相似程度；必要時對官方檢索報表留存日期畫面。
3. 優先處理《向光》官方同名半年刊與站內「向光｜TOWARD OPEN SKIES」標籤，判斷是否須透過版面明確顯示「由己的學習與活動欄目」來降低混淆。
4. 確認有具體案號與實際可能衝突時，再考慮商標專業諮詢。非營利、免費本身**並不等於完全豁免商標爭議**。

## 第二輪｜臺灣官方法律與實際使用再確認（2026-10-17）

本輪直接回查 [TIPO商標檢索系統](https://cloud.tipo.gov.tw/S282/S282WV1/)（當日頁面顯示資料庫更新至2026-10-11）及 [TIPO商標查詢操作說明](https://www.tipo.gov.tw/tw/tipo1/834-1255.html)。官方搜尋介面具備簡易搜尋、文字近似、圖形近似與指定商品服務分類；但這次的文字網頁查詢工具不能替互動表單逐筆提交6組文字、取得各案正式登錄紀錄或核對2026年即時有效狀態。因此**現階段沒有查到能正式證明六組在臺灣已註冊或未註冊的案件清單**，不把一般Google無結果當清白證明。

### 確定有公開使用、值得避開讀者混淆者

- **向光**：國家人權博物館現行 [出版品索引](https://www.nhrm.gov.tw/w/nhrm/Publishing?index=4) 和 [出版展示](https://www.nhrm.gov.tw/w/nhrm/index/ExhibitionB) 實際列出《向光》半年刊創刊號、多期至第十三期。其2022年報直接稱《向光：人和人權的故事》半年刊。**這證明出版刊名在先使用，不等於TIPO已註冊商標，也不能直接斷言《由己》的欄目侵權。** 但兩者都是知識文章／出版內容，若只是單獨寫「向光」作閱讀欄目，存在品牌辨識重疊，是目前優先避嫌對象。
- **由己**：臺灣 App Store 確實有北京公司推出的 [「由己」遠距工作平台 App](https://apps.apple.com/tw/app/%E7%94%B1%E5%B7%B1/id1634342655)，內容著重在線用工、工作媒合。另二手資料聲稱「由己」在中國大陸2017年註冊（不能據此確認臺灣有同案權利）。臺灣《由己》是免費女性生活與資源閱讀網站，服務定位存在差別，**保留中文主品牌；先查TIPO與實際混淆風險，不需要立即改名**。

### 同音字不等於自動安全

TIPO [商標近似判斷基準](https://www.tipo.gov.tw/trademarks-tw/dl-280016-cfbd6f2d0de04a86b65a061645abc68d.html) 含外觀、讀音、觀念等因素；[官方Q&A](https://www.tipo.gov.tw/tw/trademarks/568-7692.html) 亦說明加不同圖形仍可能因相同文字引起混淆。因此若「向光」需要調整，`嚮光` 雖為**同音且意義接近**的漂亮候選，法律上仍可能被認為相似，**不能當作避險完成**；只是保留讀音的文字提案。

### 官方原則與取捨

- [TIPO：短的書名常不受著作權保護，但具來源識別能力的名稱可能涉及商標](https://www.tipo.gov.tw/tw/copyright/692-16174.html)。因此存在同名半年刊本身**不是侵權證明**。
- [TIPO：商標、公司／商號、網域分屬不同制度](https://www.tipo.gov.tw/tw/tipo1/814-1211.html)；網域不同或做公益不會讓所有衝突自動消失。
- [TIPO：商品服務類別與混淆仍需綜合個案判斷](https://www.tipo.gov.tw/tw/trademarks/568-7732.html)。線上出版、教育閱讀應優先注意第41類，其他實際指定服務亦應檢視。

**下一步僅需操作TIPO互動商標查詢表單取得各案有效狀態、權人、類別。對「向光／嚮光／展頁／拓頁／閱野」先查41類，中文主品牌由己與三組英文並行查。不需申請、不需支付費用即可查詢。**

## 補查候選「向望」（2026-10-17）

站主提出「向望」作為原「向光」閱讀欄目的備用。公開資料**確實已有文化與出版領域使用「向望」**：
- 嘉義市政府文化局2025年「桃城文學什光紀／迴響嘉義321」系列活動，其三主題之一即為「**向望：市集×電影×野餐日×文學裝置展**」，於2025年10月新聞稿／轉載報導明確存在；是閱讀、文學、藝文活動同領域的**實際使用**，但不代表已將「向望」兩字單獨註冊為商標。[新聞轉載](https://news.pchome.com.tw/public/idn/20251007/index-75982051399722224016.html)。
- 2025年12月出版之《台灣 ê 故事－寫予咱 ê 島嶼（3）：**咱人 ê 向望**》確有出版品通路資料。這是**書名中含「向望」**，並非同名獨立品牌的商標證據。[三民書店](https://www.sanmin.com.tw/search?au=%E5%BB%96%E5%93%81%E7%A1%AF)。
- 2026年《戰後台灣史：**一個新國家的向望**》亦為現有出版品，屬片語使用，不等於「向望」已註冊商標。[momo書籍](https://www.momoshop.com.tw/product/15228913)。
- 普通網路精確搜尋尚未看到能核實的**臺灣智慧財產局「向望」單獨文字商標註冊案號或有效狀態**。這是「目前未找到公開搜尋命中」而非「TIPO查無」，**仍須用TIPO商標檢索系統互動表單查第41類與相近服務**。[TIPO官方檢索操作說明](https://www.tipo.gov.tw/tw/trademarks/568-7691.html)。

**暫定評估：** 相比「嚮光」，「向望」的讀音／意義和「向光」已不同，語義適合探索與展望；但**在文學閱讀領域已被用作活動主題**，不能說是沒人使用的全新名稱。先列可考慮備選，**不是核准可上線的新欄名**。不要修改站內名稱，等確認TIPO案件與站主選擇。

## 第三輪｜2026-10-17 官方檢索最後驗證界線

已找到智慧財產局官方開放資料 [商標權狀態異動資料 API](https://cloud.tipo.gov.tw/S220/opdata/detail/API11) 和 [商標權及關聯案件開放資料 API 說明](https://www.moea.gov.tw/MNS/populace/news/wHandNews_File.ashx?file_id=96954)：

- 正式 API 支援 `tmarkname` 對商標名稱做模糊比對；可取得申請號、註冊號、權利人、指定商品／服務等。但官方手冊明示**須先申請 API 驗證碼 `tk`；未通過驗證僅提供範例資料**，無法把無驗證碼的結果當正式搜尋報表。
- 已實際再次開啟 [智慧財產局商標檢索系統](https://cloud.tipo.gov.tw/S282/S282WV1/)：首頁可讀取商標文字輸入欄位、文字近似查詢及資料更新日（2026-10-11）。但本輪文字擷取工具無法對官方互動表單輸入／送出查詢，因此無法取得「向望」或六組品牌在第41類的逐案清單。
- 嘗試透過公開網路搜尋定位「向望」「向光」「由己」臺灣TIPO註冊案件，結果**未取得可辨認商標權人、申請案號及指定類別的官方案件證據**；不可說查無、可使用或已被他人註冊。已知《向光》實際同名半年刊是**出版物使用證據**，不是註冊商標案件。
- 原始資料集僅涵蓋特定已公告／申請資料範圍，且新申請案可能有建檔時差；即使取得資料仍要看最新有效狀態、相關類別與近似判斷。

**結論：本次能完成的是資料來源、使用情況、可比對類別與查核技術門檻確認；尚未完成「向望／向光／由己」等的官方案件級相同／近似查詢，不能把前幾輪的初步查詢列成法律安全驗收通過。** 下一步需要可互動瀏覽器實際在官方系統輸入查詢，或持有合法核發的驗證碼查API；不需付費申請商標，也不需先改站名。
