# 《由己》三批資料與圖片發布核准紀錄（2026-10-15）

**來源**：網站發起人於 2026-10-15 ChatGPT 對話明確表示「我同意《由己 SELF-AUTHORED》以下批次資料納入未來正式版：16 筆官方及機構入口、4 支專線及 110 簡訊入口、9 張現有 AI 圖片。此為資料與圖片發布核准，不代表同意現在合併 main 或正式部署。」

**已記錄的核准範圍**：
- 16 筆機構／服務官方入口：只核准基本入口資料及自行整理且有來源佐證的簡介；詳細申請資格、費用、逐一電話／時段資訊不屬此批。原網站無法直接讀取的 `mohw-sps`、`sfaa` 未核准。
- 110、119、113、1925：依官方資料核對的主要用途、服務時間與號碼。另准許警政署 110 SMS 文字簡訊說明的官方連結，不包含 110 視訊 App 隱私政策作下載入口。
- 九張已有 AI 圖像：沿用現有生成圖、既有局部修補及裁切；`cat-city` 保留避開類 101 地標的原裁切（banner 1320px，放大可能略柔）；保留 AI 非實景揭露。可選文章封面 `article-how-to-use` 未補，不屬此批。

**查核與核准分離**：AI 官方來源比對日期及範圍保存在各資料的 `review`；作者發布核准日期及版本快照在 `content/release-approvals.json`。原 `status: 待確認` 與 `checkedAt: null` 沿用人工逐頁查核的原義，沒有冒充作者完成人工核對。這項批次核准也不是侵權、商標或法律專業審閱的擔保。

**版本綁定**：正式版只會接受與核准時 JSON 內容完全一致的機構／專線；照片同時鎖定核准之圖片描述、裁切、原始 PNG Git blob 指紋、產物資訊及各尺寸輸出檔指紋。如後續有實質變更必須取得新核准，不能延用此批次決定。

**部署限制仍有效**：本次僅允許未來正式版使用上列資料，不代表准許 GitHub Pages 發布。開發分支可做必要技術調整與 CI 測試；待商標、實機、備份與最後整合驗收完成，另由網站發起人同意才可合併 `main` 或部署。
