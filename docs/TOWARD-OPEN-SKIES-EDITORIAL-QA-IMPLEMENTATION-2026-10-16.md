日期：2026-10-16。**僅獨立 QA 實作，不代表已公開部署、站主正式核准或合併 main。**

## 一、已確認必須合併理解的兩次發起人回饋

1. 六大主題 = 各種生活需求的開口；讀利與向光 = 帶進文章閱讀的兩個目錄。
2. 讀利 = 全站有用的文章、生活制度、各面向知識；向光 = 透過選題探索學習、活動、文化、人物、公益、藝文、生活技能與興趣，**不是只有官方機構卡**。
3. 向光原八個索引（婦女中心課程、就業培訓、創業講座、家庭教育、育兒與親職課程、生活技能、免費或公開報名的進修活動、地方政府教育及福利活動）保留，每一項需要實際可讀文章。
4. 另外收納有閱讀價值的成人文化故事、女性創業人物、公益行動、音樂表演、生活小知識、數位素養、日常創作，**不需要替每個題目再新增網站主分類／空白選單**。
5. 避免「向光」重複城市與福利 22 縣市按鈕造成手機頁面很長，也避免重複全尺寸的官方資源卡；城市僅留簡短入口，正式來源在文章底部或少量文字清單。
6. 同篇文章維持單一 slug，可在讀利、主題分類、向光多處顯示，永遠不重複儲存或維護全文。
7. 主要讀者高中生以上至約 70 歲，文體成熟且有實際資訊；避免兒童化的天文／植物辨識、過度政治或催淚敘事。

## 二、GitHub 已做的技術工作（PR #5，獨立分支）

- `scripts/lib/toward-light-editorial.mjs`：把八個索引明確對應到現有 30 篇 QA 文章，四篇精選與三個短型正式入口由文章和資源 id 校驗。找不到文章會使 QA build 失敗，不容許出現空項目。
- `scripts/build.mjs`：**只有 QA 模式**將向光改成文章導向。上方四篇精選卡；八個無 JS 的 `details/summary` 收合群組；每個展開顯示同站文章；底下連向 learning.html 與 city.html 的兩個短型入口，再提供少量官方外連；除去「向光」重複的 22 縣市完整按鈕及巨型資源卡。
- `src/assets/css/main.css`：響應式收合、可換行標題、可操作面積、鍵盤焦點及 `prefers-reduced-motion`。
- `tests/qa-batch2.test.mjs`：檢查八個索引有文章、四篇精選、三個官方來源、沒有長城市清單／大卡，且手機可以展開連到站內文章；既有搜尋、六大分類、30 篇文章與正式發布門檻測試不刪減。

**隔離**：一般預覽和正式版保留既有向光 HTML，不合併 `main`、不改 `content/` 與 `release-approvals.json`，不觸發公開 QA Pages；PR #5 暫列 draft，以免與 Claude Issue #3 同時改 `scripts/build.mjs`。待 Claude 完成 Issue #3 後才以新 HEAD 更新、解決衝突並整批測試。
