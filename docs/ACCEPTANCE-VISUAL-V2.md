## 一、先說結論：本輪最大的缺口

**寫實攝影素材目前 0 張。** 本開發環境：

- 沒有任何圖像生成工具（已確認可用工具清單中沒有圖像生成功能）。
- 網路政策封鎖外部圖片來源（實測 Unsplash、Wikimedia、Hugging Face 皆被拒絕連線）。
- 依指令不得擅自下載網路圖片，也不得裁切參考示意圖代替。

因此本輪完成的是**整站版面、配色、字體與圖片系統的重製**，所有照片位置都已依指定比例預留，在預覽版以「攝影素材待補」框標示（正式版不會出現這段文字）。照片放入後不需修改任何程式，執行 `npm run images` 即可套用。

**在照片補齊之前，本輪無法通過「寫實生活攝影」這一項視覺驗收，這點不因自動化測試通過而改變。**

### 素材加入流程（已建置完成）

1. 原圖放到 `content/photos/originals/<id>.jpg`。
2. `npm run images`：依各位置比例自動裁切，輸出 480–2400px 多尺寸 WebP＋1200px JPEG，並移除 EXIF／GPS。
3. 網站自動輸出 `<picture>`：首頁與分類頁在手機改用另一個裁切（直幅或 4:3），首屏圖片優先載入，其餘延遲載入。
4. 依視覺規範第四章完成 8 項檢查，在 `photos.json` 填寫來源、授權與日期，`status` 改為「已檢查」後，正式版才會使用。
