## 查核方式與限制

- 開發環境無法連線 `.gov.tw` 網站，因此新增只供人工查核用的 GitHub Actions 工作流程（`.github/workflows/verify-sources.yml`、`scripts/verify-sources.mjs`）。它在 GitHub 的美國東部機房連線到官方網頁，把頁面標題、更新日期與正文印在執行紀錄，由 Claude 逐頁閱讀原文。2026-10-15 起工具已收斂輸出：只印網址、連線狀態、標題、頁面日期與少量 ±30 字短摘錄（遮蔽電子郵件），不再印出正文。**搜尋引擎摘要只用來找網址，沒有當成查核結果。**
- 執行紀錄：run [38608177067](https://github.com/daycool858000-hue/morning-light-magazine/actions/runs/38608177067)（全部來源）、[38608659630](https://github.com/daycool858000-hue/morning-light-magazine/actions/runs/38608659630)（第二輪主要內容）、[38608984132](https://github.com/daycool858000-hue/morning-light-magazine/actions/runs/38608984132)（第三輪：1925、1980、119）。
- 「讀到官方頁面」不等於本站已完成人工查核：依本站定義，「已確認」須由使用者人工比對。**所有資料 `status` 維持「待確認」、`checkedAt` 維持 null**，只依官方原文修正文字。
- 部分網站從海外機房無法連線（逾時、憑證鏈不完整、Cloudflare 阻擋），列為「本輪無法查核」，沒有用其他來源推測內容。
