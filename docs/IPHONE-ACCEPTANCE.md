# 用自己的 iPhone Safari 驗收正式版（不公開網站）

> **2026-10-16 現況附註（Issue #1 工作 D）**：網站擁有人已將 GitHub Pages 來源設為 GitHub Actions，並同意以 `qa-public-preview.yml` 發布**公開但標示「未核准測試內容」**的 QA 網站：https://daycool858000-hue.github.io/morning-light-magazine/ 。它不是正式上線，`main` 未合併；noindex 也不代表私密，知道網址的人都能看到。目前驗收新內容直接用 Safari 開啟上述 QA 網址即可；下文同 Wi-Fi 電腦預覽仍可用於驗收「正式版」建置。以下為建立當時的歷史紀錄，保留原文。最新狀態見 [完整交接](HANDOFF-2026-10-15-SELF-AUTHORED-COMPLETE.md)。

目的：讓網站擁有人在**自己的 iPhone Safari** 上，實際操作「正式版」網站（只含已核准的資料與圖片），而**不把網站放到網際網路上**。

## 建議做法：同一個 Wi-Fi 的電腦預覽（免費、不公開）

原理：電腦在家中 Wi-Fi 內暫時提供網站，iPhone 連同一個 Wi-Fi 用 Safari 開啟。網站不會上傳到任何服務；網址中有一段每次啟動都不同的隨機字串，同一個 Wi-Fi 的其他人也猜不到；60 分鐘後自動停止。

需要：一台 Mac 或 Windows 電腦、iPhone、兩者連同一個家中 Wi-Fi。不需要 GitHub 帳號操作，不需要付費。

### 第一次準備（只做一次）

1. 在電腦安裝 **Node.js**：到 https://nodejs.org 下載標示「LTS」的安裝檔，一路按「下一步」完成。

### 每次驗收

1. 下載最新開發版網站檔案（直接點連結即可，會下載一個 ZIP）：
   https://github.com/daycool858000-hue/morning-light-magazine/archive/refs/heads/claude/morning-light-visual-v2.zip
2. 解壓縮，得到資料夾 `morning-light-magazine-claude-morning-light-visual-v2`。
3. 在這個資料夾開啟指令視窗：
   - **Mac**：在 Finder 對資料夾按右鍵 →「服務」→「新增位於檔案夾位置的終端機視窗」。若選單裡沒有這項：打開「終端機」App，輸入 `cd `（cd 後面有一個空格），把資料夾拖進視窗，再按 Enter。
   - **Windows**：打開資料夾，在上方網址列輸入 `cmd` 後按 Enter（請用「命令提示字元」，不要用 PowerShell）。
4. 輸入下面這行後按 Enter（不需要先安裝其他套件）：
   ```
   npm run phone-preview
   ```
5. 畫面會顯示一個網址，例如 `http://192.168.1.23:4173/3f9a0c1b2d4e/index.html`。若電腦詢問是否允許連線或防火牆，請只允許「私人網路」。
6. iPhone 連上同一個 Wi-Fi，打開 Safari，輸入那個網址。
7. 驗收完成後，在電腦的指令視窗按 `Ctrl + C` 停止（60 分鐘後也會自動停止）。

看到的就是**正式版**：只有已核准的 16 筆機構入口、4 支專線、110 簡訊入口與 9 張圖片；沒有「預覽版本」橫幅。

| # | 操作 | 預期結果 | 結果 |

| 7 | 支援資源頁點警政署簡訊報案連結、任一「前往官方網站」 | 開啟官方網站 | ☐ |

### 這個方法的限制

- 網址是 `http://` 的區網位址，不是未來正式的 `https://…github.io/morning-light-magazine/`。網站功能不依賴兩者的差異，但不存在的網址顯示的 404 頁「回首頁」按鈕，在這個預覽中會連到錯的位置（正式網址下正常）。
- 需要電腦和 iPhone 在同一個 Wi-Fi；公司或公共 Wi-Fi 可能封鎖裝置互連，請用家中網路。
- 在電腦執行期間，同一個 Wi-Fi 的人如果知道完整網址也能開啟，因此請只在可信任的 Wi-Fi 使用、用完立即停止。
- 撥號只驗證「iPhone 會跳出撥號詢問」，不要實際撥出；本站不保證定位或派遣。

## 評估過但不採用的其他方式

| 方式 | 免費 | 不公開 | 簡單 | 結論 |
|---|---|---|---|---|
| **同 Wi-Fi 電腦預覽（上方做法）** | 是 | 是（只在區網、隨機網址、自動停止） | 中（需一次安裝 Node.js） | **採用** |
| GitHub Pages 測試站 | 是 | 否（公開網站；私人 Pages 需企業付費方案） | 是 | 違反「不公開、不部署」，不採用 |
| 通道服務（ngrok、Cloudflare Tunnel 等） | 多為免費 | 否（產生網際網路可連的網址） | 中 | 等於建立公開測試站，不採用 |
| 有登入保護的託管（Cloudflare Pages＋Access、Netlify 密碼保護等） | 部分免費 | 是（需登入） | 低（需新帳號與設定） | 屬新增外部服務，需你另行決定，本輪不執行 |
| 把 ZIP 傳到 iPhone 用「檔案」打開 | 是 | 是 | 是 | iPhone 無法用 Safari 正常開啟本機多檔網站（樣式、腳本、圖片會失效），結果不具代表性，不採用 |
| Mac 的 Xcode iPhone 模擬器 | 是 | 是 | 低（需下載數 GB） | 不是實機，只能當輔助 |
| 雲端實機測試服務（BrowserStack 等） | 否 | 需上傳或通道 | 中 | 付費，不採用 |
