## 四、連結檢查器修正

`scripts/check-links-browser.mjs` 改為四類輸出（✔ 正常開啟／⇩ 下載型連結／… 海外逾時或受阻／✘ 真正失效），結尾列出四類數量並提醒「工作流程 success 不代表每個網址都正常開啟」：

- **下載型連結**：導覽丟出 `Download is starting` 時，改以 HTTP 讀取狀態、`content-type` 與檔案大小（不輸出檔案內容）；HTTP 成功且有內容才算下載型可用。
- **真正失效**：只有 HTTP 404／410，或 `ERR_NAME_NOT_RESOLVED`、憑證錯誤等。
- **海外逾時／受阻**：逾時、連線被拒、403、防護驗證頁、其他 HTTP 錯誤——不等於失效，不得據此刪除來源。
- 新增 `--fail-on-broken`：只有「真正失效」才 exit 1。`qa-links-browser.yml` 的九篇步驟已加上此參數；其他組別維持只報告，避免既知的海外阻擋讓工作流程變紅。
