## 六、自動化測試

測試由 31 項增加為 39 項。原有 31 項全部保留，門檻沒有降低。新增 8 項：

1. 頁首在 320／375／390px、頂端／捲動後／選單開啟時：兩個目錄與切換畫面可見、品牌文字與按鈕互不重疊、不超出畫面、點擊區 ≥ 44px、無水平溢位
2. 點擊兩個目錄前往正確頁面；兩頁前段都有支援資源入口，連往同一個支援資源頁；全站只有一個支援資源頁
3. 手機選單第一項為支援資源
4. 原首頁內容可由內頁抵達
5. 六大主題卡依序開啟六個分類頁
6. 快捷入口恰好 4 個且順序、中英文正確
7. 有急事只有手電筒、不顯示號碼
8. 有急事為單一 `tel:110`，無中間頁或彈窗

不新增追蹤、會員、資料蒐集或外部依賴，由原有的「無第三方請求」「無表單與本機儲存」等測試持續把關。

**開發中發現並修正的問題**：第一版頁首在 320／375px 時，「SELF-AUTHORED」文字會溢出，蓋到選單圖示與「切換畫面」按鈕；390px 選單開啟時也會碰到關閉鈕。原本的重疊測試量的是品牌連結的外框，沒有量到溢出的文字，所以沒抓到。處理方式：

- **版面修正**：440px 以下的標誌改為「由己」在上、SELF-AUTHORED 在下。
- **測試修正**：改用文字實際範圍量測，並加入「選單開啟」狀態。

已驗證新測試在修正前的樣式會失敗、修正後通過。

**第一次推送後 GitHub Actions 失敗（commit `408cc45`）**：[Run 38595636174](https://github.com/daycool858000-hue/morning-light-magazine/actions/runs/38595636174) 為 39 項通過 38 項。

- **失敗內容**：在 320px 寬度，CI 主機的英文字型略寬，「SELF-AUTHORED」碰到選單圖示（本機量測當時兩者只相距 6px）。
- **修正**：只在 359px 以下收緊頁首間距，元素與文字都沒有刪減：
  - SELF-AUTHORED 字距 0.18em → 0.1em
  - 葉枝圖形 30px → 26px
  - 頁首按鈕左右內距 9px → 7px
- **結果**：本機 320px 的間距由 6px 增加到 33px。
- **測試門檻未修改**。
