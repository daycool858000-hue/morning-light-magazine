## 二、哪些索引內容足夠，哪些仍薄弱

| 索引 | 判斷 | 理由 |
|---|---|---|
| 創業講座 | **足夠** | 兩篇都有具體經營知識（現金流三情境、資金與諮詢的差別），不只是入口介紹。可再加 batch4-business-registration（登記與稅籍），同屬開業知識 |
| 生活技能 | **足夠** | 三篇都是可直接應用的生活財務與消費知識 |
| 免費或公開報名的進修活動 | **足夠** | 三篇分別說明不同學習平台的權限與限制，內容與索引名稱吻合 |
| 就業培訓 | **基本足夠，深度有限** | 有「怎麼選課、怎麼看補助」的實用判斷；但沒有一篇說明訓練實際學什麼、課後如何銜接求職。batch2-03（重新找工作）可補職涯銜接，但目前不在此索引 |
| 婦女中心課程 | **部分足夠** | 第六批篇說明中心有哪些服務（含課程與培力），但沒有「課程怎麼選」的內容；另兩篇是查詢方法與機構層級 |
| 家庭教育 | **薄弱** | 沒有任何一篇講成年人之間的家庭關係或家庭教育的內容本身；一篇是查詢方法，一篇是心理健康閱讀資源 |
| 育兒與親職課程 | **名不符實** | batch2-02 是育兒津貼與托育補助，屬福利申請，不是親職學習；另一篇是查詢方法 |
| 地方政府教育及福利活動 | **薄弱** | 兩篇都是「怎麼找活動」，沒有說明不同活動形式的參與經驗；「福利活動」部分也沒有對應文章 |

結論：**4 個索引有內容支撐（創業、生活技能、公開進修、就業培訓），4 個需要專門文章補強（婦女中心課程、家庭教育、育兒與親職、地方活動）**。這與 ChatGPT 第二輪報告的判斷一致。不需要新增分類按鈕。

## 五、站主核准後需要修改的程式與資料檔

**單一文章、多處引用的現有做法（不需改架構）：**
- 每篇文章只有一個物件、一個 slug、一個 `articles/<slug>.html` 頁面。
- **讀利**：導讀文章區自動列出所有 QA 文章。
- **六大主題**：依文章的 `category` 自動出現在該分類頁（城市與福利頁另有自己的區塊）。
- **向光**：`TOWARD_TOPICS` 與 `TOWARD_FEATURED` 只存 slug 清單，指向同一篇文章。
- **搜尋**：每篇只建一筆索引。

**需要修改的檔案：**

1. **合併編輯分支的第二版全文**：把 `editorial/batch7-9-source-review-20261016` 的三份 docs 合併進開發分支（只是 docs，不改原稿）。
2. **新增載入器** `scripts/lib/qa-batch7-9.mjs`，沿用 `qa-batch45.mjs` 的 `loadArticleDocs`。需先擴充共用解析：
   - **參考來源段落**：新稿用 `### 來源與延伸閱讀`、`### 正式來源`、`### 官方來源與延伸入口`、`### 官方來源與延伸閱讀`、`### 官方研究與教育參考來源`、`### 正式來源與延伸入口` 等標題；目前只認粗體行，需加入 `###` 標題寫法。
   - **篇首說明行要排除**：`**主題：**`、`**建議入口：**`、`**內容狀態：**`、`**建議收錄：**`、`**對應向光：**`、`**建議歸類：**`。這些是向光位置建議，不是六大分類，因此分類改由對照表指定，略過「原稿分類需一致」的檢查。
   - **來源後的編輯備註要排除**：`編輯查核`、`查核與授權備註`、`查核備註`、`編輯備註（不公開）`。
