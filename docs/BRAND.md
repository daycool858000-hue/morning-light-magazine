## 標誌組合（lockup）

頁首與頁尾使用同一組標誌，由左至右：

1. 葉枝圖形 `src/icons/logo.svg`（原創，琥珀棕）。
2. 「由己」：系統明體，粗體，主要識別。
3. 細分隔線。
4. 上行「SELF-AUTHORED」（無襯線、大寫、加寬字距、琥珀棕），下行主題說明（暖灰）。

規則：

- 中文「由己」永遠是最大、最先被讀到的文字；英文只作搭配，不單獨取代中文。
- 螢幕寬度 600px 以下隱藏主題說明，只保留「由己」與 SELF-AUTHORED（440px 以下改為上下排列，見下方說明）。
- 不加外框、徽章、漸層、陰影或其他裝飾。
- 瀏覽器標題格式：`頁面名稱｜由己 SELF-AUTHORED`；首頁為 `由己 SELF-AUTHORED｜女性生活、權益與在地資源指南`。

## 2026-10-15 最新商標初查

六組現行名稱的初步資料檢查詳見 [商標公開資料初查](TRADEMARK-PRELIMINARY-2026-10-15.md)。已查到部分境外同名使用，尚無足以判定必須更名的臺灣官方具體案號；**智慧財產局互動系統的六組個案文字近似檢索仍未完成**。網站發起人目前不打算支付費用申請商標，也沒有批准重新命名。不得把初步網路查詢冒充臺灣官方完整檢索。

## 2026-10-17｜向望專欄更名（使用者確認）

- **新名稱**：「向望｜TOWARD OPEN SKIES」。第一閱讀專欄「讀利｜THE CONSIDERED PAGE」、主品牌「由己 SELF-AUTHORED」保持不變。
- **決策背景**：由臺灣智慧財產局官方檢索，使用者提供Manus案件明細；「向望」文字近似搜尋的4筆案件均非完全同字、類別不屬出版教育，而「向光」與國家人權博物館刊名同名且有第41類同音近似申請紀錄。此更名為合理降低混淆疑慮，不能當作已取得商標註冊。
- **固定路徑**：保留 `toward-light.html`、內部ID `toward-light`、CSS selectors 與八個入口；既有44篇QA文章、18篇專欄文章、六大主題與已刊內容不改。
- **發布界線**：QA分支更新與實際 GitHub Pages 部署是兩件事。網站與正式版共用網址，若要以QA內容覆蓋仍必須透過原有的 GitHub Actions 手動確認字串；不得繞過。
- 本文「名稱沿革」中引用的「向光」屬歷史記錄，不應全部取代。
