## 六、網站擁有人如何查看測試畫面

第一次要先在電腦安裝 **Node.js**（https://nodejs.org ，下載標示 LTS 的版本，一路按下一步）。之後每次：

1. 下載最新開發版（點連結即可）：
   https://github.com/daycool858000-hue/morning-light-magazine/archive/refs/heads/claude/morning-light-visual-v2.zip
2. 解壓縮後打開資料夾，在上方網址列輸入 `cmd` 按 Enter（Windows「命令提示字元」）。
3. 依要用哪台裝置看，輸入下列其中一行後按 Enter：

| 想在哪裡看 | 輸入 | 然後 |
|---|---|---|
| **Windows 電腦本機** | `npm run qa-preview` | 用 Edge 或 Chrome 開啟 `http://127.0.0.1:4173/index.html` |
| **iPhone Safari** | `npm run qa-phone-preview` | iPhone 連同一個家用 Wi-Fi，用 Safari 輸入視窗顯示的網址（含一段隨機字串）；60 分鐘後自動停止 |

4. 看完在指令視窗按 `Ctrl + C` 停止。

建議檢查：城市與福利選幾個縣市（尤其嘉義市、高雄市、連江縣）、服務類型選「婦女福利」、讀利專欄點進幾篇文章、搜尋文章標題、在地卡片按「前往官方網站」（特別是上表「待實機驗收」的縣市）。若電腦詢問是否允許連線，只允許「私人網路」。

一般預覽（`npm run preview`）與正式版（`npm run phone-preview`）不會出現這批測試內容。
