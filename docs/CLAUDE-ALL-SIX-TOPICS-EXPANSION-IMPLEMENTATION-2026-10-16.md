## 4. QA 匯入方式

- 先分為安全的一小批內容再匯入 QA，不一口氣把所有待查原稿放進公開網站。依現在 `scripts/lib/qa-*.mjs` 的來源路徑、防止發佈狀態自動改動等設計來建立新的 QA 讀稿 loader（例如 qa-expansion）；可用獨立 JSON 明確記錄每篇 slug、內容來源與原版本，避免根據文章標號自動猜。
- `preview`／`production` 不得讀入新稿、新多語與新在地候選；QA 保留 noindex、醒目「未核准測試內容」、官方來源和最後核對日期。
- 六大主題原有列表、向光 8 索引、讀利 23／向光 13 既有卡與原始文章都不刪改；新稿要歸類，向光／讀利按內文定位分流，不可重複在兩個目錄各產生第二篇文章。
- 文字要真正可讀：段落、例子、制度限制、官方延伸來源，不能用標題加兩句話冒稱完成。未必每篇都要圖片，勿擅用第三方圖片或商標。
- 新住民 13 項依官方主管機關／地方適用性整合；同 URL 不產生第二張卡，同機構不同 URL 可以分別為文字入口；NI-08 的非 gov.tw 專站要能找到地方政府正式來源證明。NI-03／NI-06 等官方同機構不同教材網址可以輕量多行文字呈現，不要因同單位就丟掉不同資料。
- 22 縣市要補 **實際的在地婦女中心、家庭教育／成人課程、社福據點**；資料不足可保留「查核中」，不得新增不存在的地方站，勿把其他縣市資源顯示成全國服務。
